# Ray Tracer

A multi-threaded path tracer in C++17 following the RTIOW series.

## Build

```bash
cmake -B build
cmake --build build
./build/ray_tracer
```

Output: `output.ppm`

## Features

- [ ] Basic ray tracing
- [ ] Materials (Lambertian, Metal, Dielectric)
- [ ] Anti-aliasing
- [ ] Camera control
- [ ] BVH acceleration
- [ ] Multi-threading
